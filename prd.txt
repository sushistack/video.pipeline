# PRD v2.1: Project "Video Pipeline" (Ubuntu/ROCM & GPT-SoVITS Edition)

**Vision:** Ubuntu 24.04 LTS 기반, AMD GPU(ROCM)를 극한으로 활용한 고성능 다국어 영상 자동화 파이프라인.
**Target Metric:** 10분 분량 영상 처리 시 **Total Turnaround Time 5분 이내** (Human Review 제외).
**Stability:** 주 50개 영상 처리 기준 **Fail Rate 1% 미만**.
**Platform:** **Ubuntu 24.04 LTS** (Production) / **macOS Sonoma+** (Dev/Local)
**Hardware:** AMD GPU (ROCM 6.x+) or Apple Silicon (MPS).

---

## 1. 인프라 및 환경 (The Foundation)

*   **Runtime:**
    *   **Core:** Python 3.12 (Managed by `uv`).
    *   **TTS Subsystem (GPT-SoVITS):** Python 3.10 (Managed by `conda` or Isolated `uv` venv).
*   **Dependency Management:** `uv` (Main), `conda` (TTS - Recommended for easy ROCM/MPS setup).
*   **Concurrency Control:**
    *   **GPU Worker:** `Semaphore(1)` - VRAM/Unified Memory 경합 방지.
    *   **CPU Worker:** `Semaphore(os.cpu_count() - 2)`.
*   **Orchestrator:** `Taskiq` + `taskiq-sqlite`.
*   **State Store:** SQLite + **WAL Mode**.

---

## 2. 파이프라인 단계별 상세 요구사항 (Technical Specs)

### [Phase 1: Ingestion & Pre-processing]

*   **Smart Watcher:**
    *   `watchdog` 사용. **파일 쓰기 완료(Stable State)** 감지.
    *   **Quota Check:** 디스크 여유 공간 10GB 미만 시 파이프라인 `Pause`.
*   **Analyzer (FFmpeg):**
    *   **Silence Detect:** `-af silencedetect=noise=-30dB:d=0.5`.
    *   **Output:** `scenes.json`.

### [Phase 2: Multilingual Transcription & Logic]

*   **Adaptive STT:**
    *   **Primary:** `Faster-Whisper (Large-v3)` with **CTranslate2**.
    *   **ROCM Optimization:** `device="cuda"` (ROCM은 CUDA 호환 API 제공) 또는 `device="cpu"` + `compute_type="int8"` 가속 확인 필요.
*   **LLM Refinement (Cost Optimized):**
    *   **Gemini-1.5-Flash:** 청크 단위 번역 및 문맥 보정.
*   **NLP Engine:**
    *   **JA:** `fugashi` + `unidic-lite` (Yomigana).
    *   **KO/EN:** Text Normalizer.

### [Phase 3: Human-In-The-Loop (HITL)]

*   **Review Interface:** `02_Review/{UUID}/draft.yaml` 생성 및 Watcher 기반 Linting.
*   **Timeout:** 24시간 `approved.lock` 부재 시 GC 후보 등록.

### [Phase 4: Synthesis (GPT-SoVITS Core)]

*   **TTS Engine:** **GPT-SoVITS** (Submodule: `worker/vendor/GPT-SoVITS`)
    *   **Reference:** [GitHub RVC-Boss/GPT-SoVITS](https://github.com/RVC-Boss/GPT-SoVITS)
    *   **Environment:** Python 3.10 필수.
*   **Installation Strategy:** `worker/init.py`가 초기 구동 시 다음을 수행:
    1.  Submodule Check (`git submodule update --init --recursive`).
    2.  Dependency Check (Micromamba/Conda or uv with specific index-url for ROCM).
    3.  Model Preload Check.
*   **Async Interface:**
    *   Main Process -> Taskiq -> **GPT-SoVITS Worker** (Isolated Process).
    *   Reason: Main(3.12)와 TTS(3.10) 런타임 분리 및 GPU(ROCM) 컨텍스트 충돌 방지.
*   **CapCut Injector:**
    *   Pro 버전 기능 사용 지양 (Free 호환성 유지).
    *   `draft_content.json` 원본 백업 및 CRC 검증 필수.

### [Phase 5: Final Delivery]

*   **Youtube Uploader (Semi-Auto):**
    *   Ubuntu Desktop 환경에서 Headful Browser로 실행.
    *   2FA 발생 시 사용자 개입 알림 (D-Bus Notification).

## 4. 에러 및 예외 처리 (Resilience)

1.  **ROCM Fallback:** ROCM 초기화 실패 시, 경고 로그 출력 후 CPU 모드로 전환(매우 느림)하거나 즉시 중단 설정.
2.  **Process Isolation:** GPT-SoVITS 워커가 크래시되어도 메인 오케스트레이터는 생존해야 함.

## 5. GPT-SoVITS 초기화 고도화 계획 (`worker/init.py` Blueprint)

"복잡한 설치 과정을 자동화하고, 멱등성을 보장하는 스마트 부트스트래퍼"

이 섹션은 사용자가 단계별로 실행하거나, `worker/init.py` 자동화 스크립트에 포함될 로직입니다.

### **[Step 1: Environment Validation]**
*   **Check Python Version:** 현재 쉘이 Python 3.10인지 확인. 아니라면 `RuntimeError("GPT-SoVITS requires Python 3.10")` 발생.
*   **Check Hardware:** `rocm-smi` 또는 `torch.cuda.is_available()`로 AMD GPU 인식 여부 확인.

### **[Step 2: Submodule Management]**
*   `worker/vendor/GPT-SoVITS` 디렉토리가 비어있는지 검사.
*   비어있다면:
    ```bash
    git submodule add https://github.com/RVC-Boss/GPT-SoVITS worker/vendor/GPT-SoVITS
    git submodule update --init --recursive
    ```
    실행 로직 내장.

### **[Step 3: Dependency Injection (ROCM Focused)]**
*   `uv` 또는 `pip`를 사용하되, **ROCM 전용 PyTorch** 설치가 핵심.
*   **Smart Installer Logic:**
    1.  `requirements.txt` 분석.
    2.  `torch` 관련 패키지는 별도 분리하여 우선 설치 (Index URL 지정).
    ```python
    # Pseudo Code
    if target_device == "ROCM":
        run_command("pip3 install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/rocm6.0")
    elif target_device == "CU126":
        run_command("pip3 install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu126")
    ```
    3.  나머지 GPT-SoVITS 의존성 설치 (`-r requirements.txt`).

### **[Step 4: Pre-trained Model Fetching]**
*   GPT-SoVITS는 기본 모델(chkpt)이 없으면 작동 불가.
*   `GPT_SoVITS/pretrained_models` 폴더 검사.
*   누락된 파일이 있다면 HuggingFace/ModelScope에서 `aria2c` 또는 `huggingface-cli`로 다운로드 자동화.
    *   `s1bert25hz-2kh-longer-epoch=68e-step=50232.ckpt`
    *   `s2G488k.pth` 등 필수 모델 리스트 정의 및 다운로드.

### **[Step 5: Monkey Patching & Configuration]**
*   **Config Injection:** GPT-SoVITS의 `config.py`나 YAML 설정 파일에 현재 시스템 경로(`pathlib` 기반 절대경로) 주입.
*   **Cleaner:** 설치 중 생성된 캐시(`__pycache__`, `.cache`) 정리.

## 6. Linus의 최종 시비
1.  **"Ubuntu 24.04 Pure Environment"**: 윈도우/맥 호환성 핑계 대지 마라. 이제 **Ubuntu Native**다. 경로 구분자, 권한 문제(`chmod +x`) 확실하게 처리해.
2.  **"Dependency Hell is Real"**: GPT-SoVITS는 의존성이 더럽기로 유명하다. `worker/init.py`가 실패하면 사용자가 수동으로 똥 치우게 하지 마라. 완벽하게 정리해서 보고해.
