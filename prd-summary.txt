1. 원본 스토리 영상에서 컷을 진행한다. (필요한 부분만 커팅) - 인간이 해야만할 듯
2. 컷씬을 기반으로 음성을 추출해 일본어 자막을 생성한다. (python3 - gemini-3-flash)
3. 발음이 중요한 음성 용 자막을 3개 (en, ja, ko)를 srt 로 생성한다. (인간 검수 필수)
4. 노출용 자막을 3개 (en, ja, ko)를 json 형태로 생성한다.
5. 4번의 노출용 자막 중 일본어(ja) 의 경우, 요미가나가 필요하기 때문에 kanjis 라는 추가 배열 필드가 필요하다. 
6. kanjis의 요소의 예시는 `{"kanji": "a", "yomigana": "aaa"}`의 형태를 갖는다.
7. 3번의 음성용 자막을 이용해 음성을 언어별 3개 뽑아낸다 (오디오 트랙 완성)
8. 1번의 컷씬 기반으로 시뮬레이션 작업을 진행한다. (인간이 해야하는 작업)
9. 메인 음성(ja)와 자막(ja) 그리고 영상의 조각들을 json 으로 순차적으로 capcut 의 json 형태로 생성하여 프로젝트 생성.
10. 효과, 자막 위치 조정 등 영상 편집을 진행한다.
11. 영상을 유튜브에 업로드하면서 자막과 음성을 입혀서 생성한다. (draft 혹은 publish 않은 상태로)
12. 11의 영상을 최종 검수하여 퍼플리싱한다.
